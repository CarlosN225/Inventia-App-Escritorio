
# Inventia

Sistema de inventario offline-first para pequeños negocios, empaquetado como aplicación de escritorio.

## Descripción

Inventia es una aplicación de escritorio que permite a pequeños negocios (como dulcerías y misceláneas) controlar su inventario sin depender de una conexión constante a internet. Registra entradas y salidas de productos, calcula existencias en tiempo real y envía alertas automáticas por WhatsApp cuando el stock llega a su nivel mínimo — incluso en zonas con conectividad limitada.

Caso de referencia: Dulcería "Los Querubines" (Nicolás Romero, Estado de México).

## Características principales

- Control de inventario (entradas, salidas y ajustes)
- Alertas automáticas por WhatsApp ante bajo stock
- Funciona sin conexión a internet (arquitectura offline-first)
- Aplicación de escritorio instalable (.exe), sin necesidad de hosting

## Stack técnico

- **Backend:** Django + Django REST Framework
- **Base de datos:** SQLite
- **Frontend:** React + Bootstrap
- **Empaquetado:** pywebview + PyInstaller
- **Alertas:** Twilio API (WhatsApp)
